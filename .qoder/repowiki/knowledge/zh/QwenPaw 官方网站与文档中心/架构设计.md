- **技术栈**：采用 React 18 + TypeScript + Vite 6 架构，使用 Tailwind CSS v4 进行样式管理，React Router v7 处理路由。
- **核心模块**：`src/pages/Docs.tsx` 实现了 Markdown 实时解析（react-markdown）与目录生成逻辑；`scripts/build-search-index.mjs` 在构建阶段预生成 `search-index.json` 以支持 Fuse.js 客户端检索。
- **国际化**：通过 `i18next` 实现中英文双语切换，文档资源按 `.zh.md` / `.en.md` 物理隔离。
- **性能优化**：页面组件采用 `lazy()` 懒加载，Vite 配置中针对 `mermaid`、`markdown` 等大体积依赖进行了 `manualChunks` 分包处理。
