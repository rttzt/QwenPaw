- **分层架构**：模块分为 `context`（短期上下文窗口管理）和 `memory`（长期记忆持久化）两个逻辑层，通过 `BaseContextManager` 和 `BaseMemoryManager` 抽象基类定义统一接口。
- **核心实现**：`LightContextManager` 负责在 Agent 推理前检查 Token 预算并触发 LLM 驱动的摘要压缩；`ReMeLightMemoryManager` 集成 `reme-ai` 库，支持向量/全文检索及后台异步总结任务。
- **主动交互子模块**：`proactive` 包实现了基于内存上下文的主动任务提取与响应生成，通过 HTTP SSE 将建议推送给前端。
- **依赖方向**：具体管理器依赖于 `agentscope` 的消息模型与 `qwenpaw` 内部的配置加载及注册中心 (`Registry`)。
