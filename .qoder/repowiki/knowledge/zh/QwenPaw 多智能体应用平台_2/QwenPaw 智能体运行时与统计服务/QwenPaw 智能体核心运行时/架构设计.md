- **核心入口与懒加载**：`__init__.py` 通过 `__getattr__` 实现 `QwenPawAgent` 和 `create_model_and_formatter` 的懒加载，避免导入重型依赖（如 `agentscope`）时产生副作用。
- **智能体实现 (`react_agent.py`)**：继承自 `ReActAgent` 并混入 `ToolGuardMixin`。负责初始化工具包（`Toolkit`）、注册技能（`skills_manager`）、构建系统提示词（`prompt.py`）以及配置内存与上下文管理器钩子。
- **模型工厂 (`model_factory.py`)**：提供统一的模型与格式化器创建逻辑。支持 OpenAI、Anthropic、Gemini 等多提供商，并通过自定义 `FileBlockSupportFormatter` 处理文件块、视频占位符及多模态消息的标准化。
- **安全守卫 (`tool_guard_mixin.py`)**：通过重写 `_acting` 和 `_reasoning` 拦截敏感工具调用。实现“拒绝/守卫/审批”流程，支持异步审批队列和强制回放机制。
- **技能管理 (`skills_manager.py`, `skills_hub.py`)**：管理本地工作区技能与远程 Hub 技能的同步、冲突解决及环境配置注入。支持从 ZIP 或 Git 源安装技能。
- **命令处理 (`command_handler.py`)**：解析并执行系统命令（如 `/compact`, `/new`, `/history`），直接操作智能体内存和上下文状态。
