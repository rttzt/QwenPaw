- **XML 处理**：使用 `defusedxml` 和 `lxml` 进行安全的 XML 解析、美化及 XSD 校验。
- **文档引擎**：DOCX 创建依赖 `docx-js` (Node.js)，PPTX 创建依赖 `pptxgenjs`，Excel 处理依赖 `openpyxl` 和 `pandas`。
- **LibreOffice 集成**：通过 `subprocess` 调用 `soffice` 进行格式转换（如 doc->docx, pptx->pdf）和 Excel 公式重算，并在 Linux 环境下使用 C 语言编写的 `LD_PRELOAD` shim (`lo_socket_shim.c`) 解决沙箱 socket 限制。
