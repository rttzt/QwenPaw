- **模块化技能结构**：按文件格式（docx, pdf, pptx, xlsx）和语言（en, zh）划分为独立的叶子模块，每个模块包含 `SKILL.md` 指导文档和 `scripts/` 实现代码。
- **DOCX/PPTX/XLSX 通用架构**：采用“解包 (unpack) -> 编辑 (edit) -> 打包 (pack)”的三段式工作流。核心组件包括 `office/unpack.py`（提取并美化 XML）、`office/pack.py`（压缩并验证）、`office/validate.py`（基于 XSD 的模式校验）以及 `office/validators/` 下的具体校验器（如 `docx.py` 处理追踪修订和注释标记）。
- **PDF 独立工具链**：不依赖解包流程，而是通过 `scripts/` 下的独立脚本（如 `check_bounding_boxes.py`, `fill_fillable_fields.py`）结合 `pypdf`、`pdfplumber` 等库进行表单处理和内容提取。
- **外部依赖集成**：通过 `office/soffice.py` 封装 LibreOffice 调用，内置 Linux 沙箱环境下的 `AF_UNIX` socket 兼容 shim；XLSX 模块通过 `recalc.py` 调用 LibreOffice Basic 宏重算公式。
- **Schema 驱动验证**：内置大量 ISO-IEC29500 和 ECMA 标准的 XSD 文件，用于在打包阶段确保生成的 Office 文档符合规范。
