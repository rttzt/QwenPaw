- 所有 Office 文档（DOCX/PPTX/XLSX）的编辑均采用先解包为 XML 目录、直接修改 XML 内容、再重新打包为 ZIP 的底层操作模式。
- 在生成或修改 DOCX 内容时，必须使用 XML 实体（如 `&#x2019;`）处理智能引号，以防止在解包/打包过程中字符损坏。
- XLSX 文件中的计算逻辑必须使用 Excel 原生公式（如 `=SUM(A1:A10)`），严禁在 Python 中计算后写入硬编码数值，以确保表格的动态性。
- DOCX 追踪修订（Tracked Changes）的插入和删除必须成对出现，且删除块内需使用 `<w:delText>` 而非 `<w:t>`，以保持 OOXML 规范一致性。
