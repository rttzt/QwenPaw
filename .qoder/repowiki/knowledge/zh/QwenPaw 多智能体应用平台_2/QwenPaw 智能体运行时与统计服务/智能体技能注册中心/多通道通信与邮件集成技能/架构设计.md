- **模块化技能设计**：采用独立的 `SKILL.md` 文件定义各通信渠道（通用消息、钉钉、邮件）的交互逻辑，通过 YAML Frontmatter 声明元数据（如名称、描述、依赖）。
- **分层指令结构**：每个技能文档内部遵循“前置条件/配置 -> 核心工作流 -> 常用命令 -> 故障排查”的逻辑分层，确保 Agent 能够按步骤执行复杂任务。
- **外部工具桥接**：作为 Agent 与外部系统（QwenPaw Runtime、钉钉开放平台、IMAP/SMTP 服务器）的桥梁，通过封装 CLI 命令（如 `qwenpaw channels send`、`himalaya`）和浏览器自动化策略来实现具体功能。
- **多语言支持架构**：针对 Himalaya 邮件技能提供中英文双版本（`himalaya-en` / `himalaya-zh`），通过独立的目录隔离语言资源，适配不同用户的阅读偏好。
