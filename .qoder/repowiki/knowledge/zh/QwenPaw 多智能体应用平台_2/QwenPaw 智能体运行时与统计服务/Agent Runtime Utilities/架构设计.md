- **入口与导出**：`__init__.py` 集中导出所有公共 API，涵盖音频转录、文件处理、消息处理、注册中心及设置工具。
- **消息处理层**：`message_request_normalizer.py` 负责在请求前对 `Msg` 对象进行深拷贝和标准化（剥离媒体块、清理特定 Provider 字段），确保不污染持久化会话状态；`tool_message_utils.py` 提供工具调用的配对校验、重排序、去重及输入修复逻辑。
- **多媒体与文件层**：`audio_transcription.py` 支持本地 Whisper 库或 OpenAI 兼容 API 进行音频转录；`file_handling.py` 实现从 Base64 或 URL 下载文件，并包含针对 `.file` 后缀的智能类型识别（HEAD 请求或魔数检测）。
- **基础组件**：`registry.py` 提供泛型类注册中心，支持通过装饰器注册和按名获取实现类；`estimate_token_counter.py` 提供基于字符数的轻量级 Token 估算器。
