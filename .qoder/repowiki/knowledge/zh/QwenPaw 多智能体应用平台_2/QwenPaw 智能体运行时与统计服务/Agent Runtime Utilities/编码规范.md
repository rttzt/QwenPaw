- 消息不可变性保护：在修改消息内容用于模型请求前，必须使用 `deepcopy` 创建副本，防止副作用影响存储的会话历史。
- 工具消息健壮性处理：在发送工具调用前，自动执行去重、无效块移除、空输入修复（从 `raw_input` 恢复）以及 `tool_use`/`tool_result` 配对校验。
- 多语言配置回退：在加载 Markdown 模板或配置文件时，若指定语言资源缺失，则按优先级（如 en -> zh -> ru）自动回退到默认语言。
- 文件类型智能推断：下载无明确扩展名的文件时，优先通过 HTTP HEAD 请求获取 Content-Type，失败后通过读取文件头魔数（Magic Bytes）进行二次推断。
