- **启动入口**：`__main__.py` 作为 CLI 执行入口，委托给 `cli.main`；`__init__.py` 负责包级初始化，优先调用 `envs.load_envs_into_environ` 恢复持久化环境变量，随后初始化日志系统。
- **配置中心**：`constant.py` 定义了全模块共享的路径（如 `WORKING_DIR`）、文件标识及 LLM 速率限制参数，内置 `EnvVarLoader` 工具类支持带类型校验和默认值的环境变量读取，并兼容旧版 `COPAW_` 前缀。
- **异常体系**：`exceptions.py` 继承自 `agentscope_runtime` 基础异常，定义了业务层专用异常（如 `ProviderError`, `ChannelError`），并提供 `convert_model_exception` 函数将底层 LLM API 错误统一转换为标准化的运行时异常。
