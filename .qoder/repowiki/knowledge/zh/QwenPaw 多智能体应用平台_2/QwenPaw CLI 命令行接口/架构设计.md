- **入口与路由**：`main.py` 定义根命令 `cli`，采用自定义 `LazyGroup` 实现子命令的懒加载（lazy loading），通过 `lazy_subcommands` 映射动态导入各功能模块（如 `app_cmd`, `doctor_cmd`），优化启动性能。
- **通信层**：`http.py` 封装 `httpx.Client`，统一处理与本地 FastAPI 服务（默认 `127.0.0.1:8088`）的 API 交互，支持从上下文或配置文件解析 Host/Port。
- **核心功能模块**：
  - `app_cmd.py`：使用 `uvicorn` 启动 FastAPI 应用服务器。
  - `doctor_cmd.py` 及配套模块（`doctor_checks.py`, `doctor_fix_runner.py`）：提供系统健康检查与自动化修复能力，支持只读检查与带备份的文件系统修复。
  - `plugin_commands.py`：管理插件的安装、卸载与验证，支持从本地路径或 URL 安装。
  - `cron_cmd.py` 等：通过 HTTP API 管理定时任务、聊天、频道等业务资源。
- **交互支持**：`utils.py` 封装 `questionary` 提供统一的终端交互提示（确认、路径选择、多选等）。
