- 所有与后端 API 交互的命令均通过 `http.py` 中的 `resolve_base_url` 解析基础 URL，优先使用命令参数，其次回退到全局上下文中的 host/port。
- 子命令模块通常导出一个名为 `*_cmd` 或 `*_group` 的 Click 命令对象，供 `main.py` 的 `LazyGroup` 动态导入和注册。
- 涉及文件系统修改的诊断修复操作（`doctor_fix_runner`）强制要求先进行备份，并支持 `--dry-run` 预览和 `--yes` 跳过确认。
- CLI 命令通过 `click.pass_context` 访问全局配置上下文（`ctx.obj`），以共享 host、port 等连接信息。
