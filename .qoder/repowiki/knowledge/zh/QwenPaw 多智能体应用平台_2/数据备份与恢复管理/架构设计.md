- **分层架构**：模块分为公共 API (`__init__.py`)、业务编排层 (`orchestration.py`)、核心操作层 (`_ops/`) 和工具支撑层 (`_utils/`)。
- **异步与线程模型**：采用 `asyncio.to_thread` 将耗时的 ZIP 压缩与文件 I/O 卸载至后台线程，并通过 `asyncio.Queue` 配合 `call_soon_threadsafe` 实现 SSE 流式进度推送。
- **原子化恢复协议**：在 `_utils/safe_swap.py` 中实现“提取到临时目录 -> 原子重命名交换 -> 清理旧数据”的三阶段安全替换机制，确保崩溃场景下的数据一致性。
- **并发控制**：通过 `asyncio.Lock` 串行化恢复请求，并利用 per-path `threading.Lock` 保护文件系统交换操作，防止跨平台（尤其是 Windows）的文件句柄冲突。
