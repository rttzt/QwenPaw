- **核心抽象与注册**：以 `provider.py` 中的 `Provider` 抽象基类定义连接检查、模型获取及实例化接口；`ProviderManager` (`provider_manager.py`) 负责内置/自定义/插件提供商的单例管理、磁盘持久化及动态加载。
- **协议适配器模式**：针对不同 API 规范实现具体子类，如 `OpenAIProvider`（兼容 OpenRouter、DashScope 等）、`AnthropicProvider`、`GeminiProvider` 以及基于本地服务的 `OllamaProvider` 和 `LMStudioProvider`。
- **高可用增强层**：通过 `RetryChatModel` (`retry_chat_model.py`) 包装底层 ChatModel，提供指数退避重试；配合 `RateLimiter` (`rate_limiter.py`) 实现全局并发控制与 QPM 滑动窗口限流，防止触发上游 429 错误。
- **能力主动探测**：利用 `multimodal_prober.py` 定义的标准化探针（红图/蓝视频），在各 Provider 中实现 `_probe_image/video_support`，通过语义校验而非单纯 API 响应来精准判定模型的多模态支持情况。
