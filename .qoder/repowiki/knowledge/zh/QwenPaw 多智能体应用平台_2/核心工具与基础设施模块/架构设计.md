- **入口与导出**：`__init__.py` 仅导出 `system_info` 中的硬件探测函数，作为模块的公共 API 边界。
- **日志子系统**：`logging.py` 定义了 `ColorFormatter`（终端彩色输出）和 `PlainFormatter`（文件纯文本），并通过 `setup_logger` 实现基于命名空间（`qwenpaw`）的日志隔离，支持 Windows ANSI 兼容处理。
- **进程管理抽象**：`command_runner.py` 提供了 `ManagedProcess` 统一封装，通过 `ThreadedProcess` 适配阻塞 I/O，并在 `start_command_async` 中实现了针对 Windows 环境的 `asyncio` 到 `subprocess.Popen` 的自动降级策略。
- **环境与遥测**：`telemetry.py` 负责匿名化环境信息采集（GPU、OS、Python 版本），利用 `httpx` 进行同步上报，并通过 `.telemetry_collected` 标记文件实现版本维度的去重与用户退出机制。
- **依赖方向**：模块内部高度自治，仅依赖根目录的 `constant.py`（获取工作目录与环境变量）和 `__version__.py`（获取版本号），不依赖业务层代码。
