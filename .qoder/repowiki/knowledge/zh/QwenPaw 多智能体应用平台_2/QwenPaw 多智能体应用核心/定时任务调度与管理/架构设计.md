- **核心管理层**：`manager.py` 定义 `CronManager`，封装 `AsyncIOScheduler`，负责任务的注册、启停、状态追踪及并发控制（通过 `_Runtime` 中的 `Semaphore`）。
- **数据持久层**：`repo/` 子包提供 `BaseJobRepository` 抽象接口及 `JsonJobRepository` 实现，采用“写临时文件后原子替换”策略确保 `jobs.json` 的数据一致性。
- **执行引擎**：`executor.py` 实现 `CronExecutor`，根据任务类型（`text` 或 `agent`）调用通道管理器发送消息或流式执行 Agent 逻辑，并支持超时控制。
- **模型与校验**：`models.py` 使用 Pydantic 定义 `CronJobSpec` 等数据结构，内置 Cron 表达式标准化逻辑（如星期字段转换）及任务参数互斥校验。
- **API 接口**：`api.py` 暴露 FastAPI 路由，提供任务的 CRUD、暂停/恢复及手动触发接口，通过依赖注入获取当前工作区的 `CronManager` 实例。
- **内置任务**：`heartbeat.py` 实现心跳逻辑，支持从配置文件读取间隔或 Cron 表达式，并在活跃时间段内读取 `HEARTBEAT.md` 触发 Agent 交互。
