- **核心入口**：`SIPChannel` 继承自 `BaseChannel`，作为模块的统一接口，通过 `from_config` 工厂方法根据配置动态实例化后端。
- **后端抽象层**：定义 `SipBackend` 协议（`backend.py`），解耦具体实现。提供 `PyVoIPBackend`（`pyvoip_backend.py`，用于本地开发，基于纯 Python 实现）和 `LiveKitBackend`（`livekit_backend.py`，用于生产环境，基于 LiveKit SIP Server 事件驱动）两种实现。
- **会话管理**：`SIPCallSessionManager`（`session.py`）负责维护活跃呼叫的状态、STT 引擎实例及 TTS 中断信号。
- **媒体处理流水线**：内置音频格式转换工具（如 `_pcm16_to_pyvoip`），处理不同后端（8kHz/8-bit vs 24kHz/16-bit）与 STT/TTS 引擎之间的 PCM 数据适配。
- **零配置开发支持**：集成 `MiniRegistrar`（`mini_registrar.py`），在开发模式下自动启动轻量级 SIP 注册代理，无需外部 SIP 服务器即可进行本地调试。
