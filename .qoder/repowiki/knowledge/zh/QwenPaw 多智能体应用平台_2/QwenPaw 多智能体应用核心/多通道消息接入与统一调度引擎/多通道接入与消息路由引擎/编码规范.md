- 所有渠道类必须定义类属性 `channel` 作为唯一标识符，并实现 `from_env` 和 `from_config` 两个工厂方法以支持不同配置来源。
- 入站消息处理遵循“原生负载 -> AgentRequest”的转换模式，通过 `build_agent_request_from_native` 将各渠道特有的 JSON 结构统一为标准运行时 Schema。
- 出站消息发送统一采用 `send_content_parts` 接口，接收标准化的 `TextContent`、`ImageContent` 等对象列表，由基类或子类负责将其序列化为渠道特定的 API 载荷。
- 渠道初始化时通过 `set_workspace` 注入 `TaskTracker` 和 `CommandRegistry` 引用，以实现任务取消控制和指令优先级识别。
