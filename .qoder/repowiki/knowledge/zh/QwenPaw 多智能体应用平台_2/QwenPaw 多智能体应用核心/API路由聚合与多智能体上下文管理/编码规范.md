- 所有需要感知当前智能体的端点均通过 `get_agent_for_request(request)` 统一解析目标 Agent ID，遵循 Header > Path > Config 的优先级策略。
- 路由模块统一采用 `router = APIRouter(prefix="/xxx", tags=["xxx"])` 模式定义，并在 `__init__.py` 中集中导入与挂载。
- 涉及文件系统或耗时操作的逻辑（如 ZIP 解压、技能扫描）均通过 `asyncio.to_thread` 或线程池执行，避免阻塞事件循环。
- 业务异常统一转换为 HTTPException，针对技能安全扫描等特定失败场景返回结构化的 JSONResponse (status_code=422)。
