- **动态路由编排**：通过 `DynamicMultiAgentRunner` 拦截 AgentApp 请求，结合 `AgentContextMiddleware` 解析上下文，将流量精准分发至 `MultiAgentManager` 管理的独立工作空间。
- **两阶段启动策略**：采用 FastAPI lifespan 实现“快速就绪 + 后台加载”，优先暴露 API 接口，随后在后台并行初始化各智能体环境、插件系统及定时任务。
- **统一生命周期管理**：在应用层统筹 `Workspace`、`PluginLoader` 及 `ChannelManager` 的启停逻辑，支持基于任务追踪的优雅关闭与零停机热重载。
- **全局状态注入**：将多智能体管理器、模型提供者等核心单例挂载至 `app.state`，供各子模块（如审批服务、命令注册表）跨域访问。
