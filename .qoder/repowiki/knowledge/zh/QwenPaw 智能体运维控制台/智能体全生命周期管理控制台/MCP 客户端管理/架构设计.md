- **页面入口**：`index.tsx` 作为主容器，负责路由渲染与全局状态（如创建弹窗）管理。
- **逻辑层**：`useMCP.ts` 封装自定义 Hook，处理 API 调用（增删改查）、数据加载及用户反馈，实现 UI 与业务逻辑解耦。
- **展示层**：`components/MCPClientCard.tsx` 负责单个客户端的卡片式展示，包含详情查看、JSON 编辑、工具列表预览等交互。
- **样式管理**：采用 CSS Modules (`index.module.less`) 进行局部样式隔离。
- **数据标准化**：内置 `normalizeTransport` 和 `normalizeClientData` 函数，兼容多种 MCP 配置格式（如 stdio, sse, streamable_http）。
