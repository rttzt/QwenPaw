- **分层架构**：采用容器-展示组件模式，`index.tsx` 作为页面容器，`useSkillsPage` 负责业务逻辑编排，`components/` 目录存放纯展示 UI 组件。
- **逻辑拆分**：通过自定义 Hook 实现关注点分离，`useSkills` 处理 API 交互与状态同步，`useSkillFilter` 负责前端搜索与标签过滤，`useConflictRenameModal` 处理命名冲突。
- **数据流**：基于 `agentStore` 获取当前智能体上下文，通过 `api` 模块执行 CRUD 操作，并利用 `invalidateSkillCache` 确保数据一致性。
- **外部集成**：内置对多个外部技能市场（如 Skills.sh, ClawHub）的 URL 解析与导入支持，并在 `components/index.ts` 中集中配置。
