- **统一布局契约**：所有子模块均通过 `PageHeader` 组件实现标准化的面包屑导航（指向 `nav.control`）与操作区布局，确保视觉与交互的一致性。
- **标准化 CRUD 模式**：各模块遵循“自定义 Hook 管理业务逻辑 + Ant Design 组件渲染 UI”的分层架构，通过 `Drawer` 承载复杂表单编辑，`Table/Card` 展示数据概览。
- **共享基础设施**：依赖全局 `api` 客户端进行后端通信，使用 `useAppMessage` 处理统一的通知反馈，并通过 `react-i18next` 实现多语言支持。
- **独立路由入口**：各子模块作为独立页面组件存在，通过前端路由系统进行切换，模块间无直接状态耦合，仅通过共享的全局 Store（如 `agentStore`）或 API 间接关联。
