- 采用页面-逻辑分离架构：`index.tsx` 负责 UI 渲染与表单交互，`useCronJobs.ts` 封装 API 调用与乐观更新状态管理。
- 组件化设计：通过 `components/index.ts` 统一导出表格列配置 (`columns.tsx`)、编辑抽屉 (`JobDrawer.tsx`) 及常量定义。
- 核心工具：内置 `parseCron.ts` 实现 Cron 表达式与用户友好格式（每日/每周/自定义）的双向转换，解决 crontab 与 APScheduler 星期映射差异。
- 依赖边界：通过 `api` 模块与后端交互，利用 `agentStore` 监听代理选择变化以刷新任务列表。
