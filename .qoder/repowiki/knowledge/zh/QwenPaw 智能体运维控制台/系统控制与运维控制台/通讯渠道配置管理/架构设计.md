- **入口与布局**：`index.tsx` 作为页面主入口，采用“卡片网格 + 抽屉表单”的交互模式，通过 `PageHeader` 提供全局筛选（全部/内置/自定义）。
- **数据层**：`useChannels.ts` 封装核心业务逻辑，负责从 API 获取渠道列表与类型，并维护内置渠道的固定排序逻辑。
- **组件层**：`components/` 目录下包含展示组件 `ChannelCard`、交互组件 `ChannelDrawer` 以及通用工具 `channelIcons` 和 `constants`。
- **授权逻辑**：`useChannelQrcode.ts` 实现通用的二维码轮询授权机制，支持微信、钉钉等渠道的扫码自动填充凭证。
- **样式隔离**：使用 CSS Modules (`index.module.less`) 确保样式局部作用域。
