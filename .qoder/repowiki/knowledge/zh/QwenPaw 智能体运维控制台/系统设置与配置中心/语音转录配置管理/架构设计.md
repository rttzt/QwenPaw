- **逻辑层**：`useVoiceTranscription.ts` 作为核心自定义 Hook，封装了所有 API 调用（获取/保存设置）、本地状态管理及派生状态计算。
- **表现层**：`index.tsx` 负责页面整体布局、加载/保存状态反馈及组件组装；`components/` 目录下的 `AudioModeCard`、`ProviderTypeCard` 和 `ProviderSelectCard` 为纯展示组件，通过 Props 接收状态与回调。
- **样式层**：采用 CSS Modules (`index.module.less`) 实现局部作用域样式，并支持深色模式适配。
- **数据流**：单向数据流，由 Hook 统一管理状态，通过 Props 下发至子组件，子组件触发回调更新 Hook 状态。
