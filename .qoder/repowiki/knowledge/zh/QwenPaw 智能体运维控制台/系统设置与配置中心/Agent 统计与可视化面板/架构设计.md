- 入口组件 `index.tsx` 负责状态管理（日期范围、加载态、错误态）、数据获取（调用 `api.getAgentStats`）以及图表配置生成。
- 子组件 `SummaryCard.tsx` 封装了带 Tooltip 的指标卡片展示逻辑，复用 `formatCompact` 进行数值格式化。
- 样式采用 CSS Modules (`index.module.less`) 实现响应式布局（Grid/Flex）及深色模式适配。
- 依赖 `@ant-design/plots` 渲染 Column 和 Pie 图表，通过 `getColumnConfig` 统一处理图表数据映射与主题配置。
