- **入口与状态管理**：以 `index.tsx` 为页面主入口，通过自定义 Hook `useProviders.ts` 封装 API 请求逻辑（如 `listProviders`, `getActiveModels`），实现数据获取与全局状态同步。
- **组件分层架构**：采用模块化目录结构，分为 `cards`（展示层，区分本地/远程提供商卡片）、`modals`（交互层，处理复杂的配置表单、模型发现与下载逻辑）以及 `sections`（布局层，包含加载状态与默认模型选择区）。
- **差异化处理策略**：通过 `ProviderCard` 和 `ModelManageModal` 等路由组件，根据 `provider.id`（如 `qwenpaw-local`）动态分发至 `LocalProviderCard`/`LocalModelManageModal` 或 `RemoteProviderCard`/`RemoteModelManageModal`，实现本地嵌入式模型与远程 API 提供商的隔离管理。
- **高级配置支持**：内置 `JsonConfigEditor` 组件，支持在 `ProviderConfigModal` 和 `LocalModelManageModal` 中对 `generate_kwargs` 进行语法高亮编辑与校验，满足高级用户的参数微调需求。
