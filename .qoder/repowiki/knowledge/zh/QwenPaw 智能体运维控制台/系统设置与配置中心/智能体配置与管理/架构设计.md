- **入口与状态管理**：`index.tsx` 为页面主入口，通过 `useAgents` Hook 封装数据获取与操作逻辑，并同步至全局 `agentStore`。
- **组件架构**：采用容器-展示模式，`AgentTable` 负责列表渲染与交互（集成 `@dnd-kit` 实现拖拽），`AgentModal` 处理复杂的表单逻辑与技能选择。
- **工具层**：`reorder.ts` 提供纯函数式的数组重排逻辑，确保 UI 更新的可预测性。
- **依赖方向**：页面组件依赖 API 模块 (`agentsApi`, `skillApi`) 进行远程交互，并通过 `PageHeader` 保持导航一致性。
