- 入口组件 `index.tsx` 负责状态管理（加载、错误、数据）及 API 调用 (`api.getTokenUsage`)。
- 采用复合视图结构：顶部为日期筛选与刷新操作，中部展示汇总卡片 (Summary Cards)，下部通过两个 `Table` 分别呈现按模型和按日期的详细统计数据。
- 子组件 `LoadingState` 和 `EmptyState` 封装于 `components/` 目录，通过 `index.ts` 统一导出，实现 UI 状态的模块化复用。
- 样式采用 CSS Modules (`index.module.less`) 进行局部作用域隔离，并包含针对深色模式的全局类名适配逻辑。
