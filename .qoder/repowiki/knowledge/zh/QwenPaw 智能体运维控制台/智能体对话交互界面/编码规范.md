- 采用自定义 Hook（如 `useIMEComposition`、`useMultimodalCapabilities`）将复杂的副作用逻辑从主组件中剥离，提升代码可维护性。
- 在 `sessionApi` 中使用单例模式导出实例，并通过 `preferredChatId` 等属性在模块间共享临时状态，避免全局变量污染。
- 通过 `window` 对象扩展（如 `window.currentSessionId`）在第三方库回调与 React 组件之间传递关键上下文信息。
- 在处理用户输入时，利用原生 DOM API（如 `nativeValueSetter`）绕过 React 的状态追踪机制，以实现程序化设置文本框值并触发事件。
