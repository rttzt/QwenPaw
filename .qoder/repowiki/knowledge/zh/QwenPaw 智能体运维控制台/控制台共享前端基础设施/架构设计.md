- **API 层**：基于 `fetch` 封装的 `request.ts` 统一处理认证头注入、JSON 解析及 401 自动重定向；通过 `modules/` 下的模块化接口定义（如 `chat.ts`, `agent.ts`）聚合为全局 `api` 对象。
- **插件系统**：采用动态模块注册机制，利用 `import.meta.glob` 发现宿主模块，并通过 Blob URL 动态加载远程插件脚本，实现路由与工具渲染器的热插拔。
- **状态与上下文**：使用 `zustand` 管理持久化的 Agent 状态（`sessionStorage`），通过 React Context 提供主题切换（支持系统偏好同步）及插件状态订阅。
- **UI 架构**：以 `MainLayout` 为核心容器，集成侧边栏导航与头部，配合 `lazyImportWithRetry` 实现页面组件的懒加载与分片错误恢复。
