## 简介

QwenPaw是一个多平台的智能代理系统，支持多种操作系统和部署方式。本文档详细列出了系统的完整要求，包括操作系统版本、硬件配置、软件依赖、网络环境以及不同安装方式的特殊要求。

## 操作系统要求

### 支持的操作系统

**Windows系统**
- Windows 10及以上版本
- Windows 11及以上版本
- 支持x64架构处理器

**macOS系统**
- macOS 14及以上版本
- 支持Intel和Apple Silicon芯片
- 支持x64和ARM64架构

**Linux系统**
- Ubuntu 18.04及以上版本
- CentOS 7及以上版本
- RHEL 7及以上版本
- Debian 10及以上版本
- Fedora 32及以上版本
- 其他主流Linux发行版（基于上述内核版本）

### 系统架构要求

- **x64架构**：支持Intel/AMD 64位处理器
- **ARM64架构**：支持Apple Silicon和ARM64处理器
- **内存管理**：支持虚拟内存和物理内存管理

## 安装方式与特殊要求

### Python包安装

**标准安装**
```bash
pip install qwenpaw
```

**开发安装**
```bash
pip install -e .
```

**特殊要求**
- 需要管理员权限进行系统级安装
- 需要网络连接以下载依赖包
- 建议使用虚拟环境隔离安装

### Docker容器安装

**Docker镜像要求**
- Docker Engine 20.10+
- Docker Compose 2.0+
- 至少2GB可用磁盘空间

**容器配置**
```yaml
version: '3.8'
services:
  qwenpaw:
    image: qwenpaw:latest
    ports:
      - "8080:8080"
    volumes:
      - ./data:/app/data
    environment:
      - PYTHONPATH=/app
```

**特殊要求**
- 需要Docker守护进程运行
- 需要适当的卷挂载权限
- 需要网络访问权限

### 桌面应用安装

**Windows安装要求**
- Windows 10/11 64位
- .NET Framework 4.8+
- 管理员权限
- 至少2GB可用空间

**macOS安装要求**
- macOS 14及以上
- Xcode命令行工具
- 管理权限
- 至少2GB可用空间

**Linux桌面安装要求**

## 性能基准与推荐配置

### 性能基准测试

**推理延迟基准**
- 小型模型（7B参数）：单次推理 < 2秒
- 中型模型（13B参数）：单次推理 < 5秒  
- 大型模型（30B参数）：单次推理 < 10秒

**吞吐量基准**
- 并发处理能力：每核心约10-15个请求/分钟
- 批处理优化：批量大小为8-32时性能最佳
- 缓存命中率：内存缓存可提升30-50%性能

### 推荐硬件配置

**开发环境**
- CPU：Intel i5-12600K或AMD R5 5600X
- 内存：16GB DDR4/DDR5
- 存储：500GB NVMe SSD
- 显卡：RTX 3060或同级别

**生产环境**
- CPU：Intel Xeon Silver 4314或AMD EPYC 7313
- 内存：64GB ECC RAM
- 存储：2TB NVMe SSD阵列
- 网络：千兆以太网

**高负载环境**
- CPU：Intel Xeon Platinum 8358或AMD EPYC 9354
- 内存：128GB+ ECC RAM
- 存储：10TB+ NVMe SSD
- 网络：万兆以太网

### 性能优化建议

- **内存优化**：启用内存池和对象复用
- **I/O优化**：使用异步I/O和连接池
- **网络优化**：启用HTTP/2和连接复用
- **计算优化**：利用GPU加速和向量化计算

## 已知限制

### 功能限制

**模型大小限制**
- 单次推理最大上下文长度：32768 tokens
- 最大并发会话数：100个
- 最大数据传输大小：100MB

**平台特定限制**

**Windows平台**
- 文件路径长度限制：260字符
- 权限管理限制：需要管理员权限
- 防病毒软件冲突：可能影响性能

**macOS平台**
- Gatekeeper限制：需要手动允许应用
- 磁盘空间限制：需要至少2GB可用空间
- 系统完整性保护：可能影响某些功能

**Linux平台**
- 权限管理：需要sudo权限
- 包管理器依赖：需要apt/yum等包管理器
- 桌面环境依赖：需要GNOME/KDE

### 性能限制

**内存限制**
- 单进程最大内存：4GB（32位）或理论无限（64位）
- 内存泄漏检测：定期重启机制
- 内存碎片化：建议定期维护

**网络限制**
- 并发连接数：受系统ulimit限制
- 带宽限制：受网络条件影响
- DNS解析超时：默认30秒

### 兼容性限制

**Python版本限制**
- 不支持Python 2.x系列
- 不支持Python 3.9及以下版本
- 不支持PyPy实现

**第三方库限制**
- numpy版本：1.21.0+
- pandas版本：1.3.0+
- torch版本：1.10.0+（可选）

## 故障排除指南

### 常见安装问题

**Python版本错误**
```bash
# 错误信息
"RuntimeError: Python 3.10+ required"

# 解决方案
python3.10 -m pip install qwenpaw
```

**权限不足错误**
```bash
# 错误信息
"Permission denied"

# 解决方案
sudo pip install qwenpaw
# 或使用虚拟环境
python -m venv qwenpaw_env
source qwenpaw_env/bin/activate  # Linux/macOS
# 或
qwenpaw_env\Scripts\activate  # Windows
```

**网络连接问题**
```bash
# 检查网络连通性
ping pypi.org

# 配置代理
export HTTP_PROXY=http://proxy:port
export HTTPS_PROXY=https://proxy:port
```

### 性能问题诊断

**内存不足问题**
```bash
# 检查内存使用
free -h
htop

# 调整配置
export QWENPAW_MEMORY_LIMIT=8192
```

**CPU使用率过高**
```bash
# 监控CPU使用
top -p $(pgrep python)

# 降低并发
export QWENPAW_MAX_CONCURRENT=4
```

### 网络问题解决

**端口占用问题**
```bash
# 检查端口使用
netstat -tulpn | grep 8080

# 更改端口
export QWENPAW_PORT=8081
```

**防火墙阻拦**
```bash
# 添加防火墙规则
sudo ufw allow 8080/tcp
sudo firewall-cmd --add-port=8080/tcp --permanent
```

### 系统健康检查

**使用内置诊断工具**
```bash
# 运行系统检查
qwenpaw doctor

# 检查网络连通性
qwenpaw doctor connectivity

# 检查资源使用
qwenpaw doctor system
```

**查看系统信息**
```python
from qwenpaw.utils.system_info import get_system_info
info = get_system_info()
print(info)
```
